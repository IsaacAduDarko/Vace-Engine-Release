About Vanta Games

Vanta Games is a small studio building VACE, a C++ game engine with a full editor, and the games that run on it. VACE is free to use. This page covers who works on it, how it came to be, how to reach us, and the license terms.

Vanta Games is made up of two people.

CEO and Lead Programmer. Isaac designed and built VACE from scratch: the renderer, the ECS core, the editor, the physics integration, the scripting ABI, and the toolchain automation in the Project Manager. He works on the engine daily and drives its direction.

How VACE came to be

VACE was not started as a commercial product. It grew out of a practical problem: the developers have always worked on low-end hardware, and the engines available at the time either did not run well on it or required a workflow that did not fit.

The engine was built on a 13-year-old Toshiba laptop (4th generation Intel Core i5, 8 GB of RAM, a GPU with no Vulkan support and no DirectX 12 support). Everything in VACE had to be efficient enough to develop and test on that machine, which shaped many of the engine's design decisions.

Before VACE, the same idea was attempted three times:

  1. Two JavaScript and WebGL prototypes. These proved the core concepts but ran into the limits of the browser and the language for a full engine.
  2. A C++ engine on OpenGL 3.3. This was the first native attempt and worked, but its architecture did not leave room to grow.
  3. VACE today. A re-architecture on OpenGL 4.3 with an expandable design, built from the lessons of the earlier attempts. The renderer, physics, scripting, and editor are all structured so that new features and backends can be added without rewriting the engine.

Vanta Games now uses VACE to develop its own games, and the engine continues to be expanded alongside that work.

License

VACE is free to use. You can download it, make games with it, and ship those games at no cost.

The source code is not open source. The engine is distributed as a binary release (editor, runtime, libraries, and headers). You may read the engine headers to write scripts against the API, but you may not redistribute or modify the engine itself.

Vanta Games has plans to keep VACE free going forward if the project receives enough support from its users. If the situation changes, existing releases will remain available under the terms they were released with, and any future licensing changes will be announced clearly in the release notes.

In short
  • Using VACE to build and ship games: free
  • Reading the headers to write scripts: allowed
  • Redistributing or modifying the engine: not allowed
  • Source code release: not planned at this time

Before you post a bug report

If the problem is a crash, a script that will not load, or a build error, include the console output from the editor. It usually contains the exact error, which speeds up a fix a lot. If you are on the Discord, the #bug-reports channel has a template.

Changelog

v0.1.0

The first public release of VACE. Editor, runtime, and bundled documentation.

Rendering

  • OpenGL 4.3 renderer behind an abstraction layer for future backends
  • PBR pipeline with HDR rendering, IBL, SSAO, bloom, and tone mapping
  • Dynamic lighting and anti-aliasing
  • Material system with data-driven shaders
  • Shader graph

Physics

  • Jolt Physics for 3D
  • Box2D for 2D

Scripting

  • C++ scripting via VACE::Script, ABI v7
  • Visual scripting
  • Plugin system

Animation and content

  • Skeletal and sprite animation
  • Animation timeline
  • Spritesheet editor
  • Inverse kinematics
  • Particle system

UI and input

  • UI system (text, buttons, sliders, images, colors, interaction events)
  • Input (keyboard, mouse, gamepads, named actions)

Architecture and tooling

  • ECS core
  • JSON save data
  • Editor: scene tree, inspector, viewport, console, project manager, toolchain settings
  • Project Manager with automated MinGW-w64 and CMake setup

Known limitations in v0.1.0

  • VACE_FIELD() inspector fields reflect in the editor but editing them does not yet change the value the running script sees
  • Windows only; other platforms are planned but not shipped
  • Some editor panels and settings may change in future releases
